# v0.1.6

- Monolith is now the production desktop UI, starting in light mode. Switch
  between light and dark using **Light theme** in the tray menu.
- Native typography, animated question transitions, selectable answers without
  a blinking caret, and expandable recent conversations inside the popup.
- **Reduce motion** in the tray menu disables UI animation for the current session.
- Copy one PNG or JPEG file in Thunar and paste to attach the image instead of
  sending its file path as text. Ordinary text paste is preserved.
- Update notifications and release notes remain accessible below **Recent**.
- The previous production UI and screenshot are archived under
  `archive/desktop-v0.1.5/`; its complete source remains at tag `v0.1.5`.

Both themes retain the same layout and behavior. Theme and motion choices apply
for the running session. Existing activation and conversation history remain
compatible. Fonts are bundled locally with their licenses.

## Release checks

Run `cargo test --locked`, `cargo check --locked --all-features`, and
`npm test --prefix web`. Run `monolith_ui` in both themes, plus the scrolling,
clipboard and lifecycle GUI checks in separate disposable X11/D-Bus sessions.
The release workflow builds and packages Linux x86_64, Windows x86_64,
macOS Apple Silicon and macOS Intel from the `v0.1.6` tag.

The mobile web UI and its version are unchanged. Production builds do not enable
`local-trial`; the optional separate preview launcher remains available to developers.
