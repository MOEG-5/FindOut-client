# v0.1.5

- Five recent conversations on desktop and web, with full threads and continuation.
- Per-answer globe and camera indicators for web search and images.
- Feedback form available before activation, optional reply email and support IDs.
- Concise app/updater download labels and release title `v0.1.5`.

Auto-updater asset filenames are unchanged. GitHub release titles are explicitly
set to the tag, restoring the v0.1.0–v0.1.3 convention.

## Rollout

Deploy the backend feedback route before publishing updated clients. Configure
`FINDOUT_AGENTMAIL_KEY` only on the backend. The sending inbox defaults to
`findout@agentmail.to` and the fixed recipient to `moeg-5@agentmail.to`.
See the backend feedback documentation for permission checks and rate protection.
The v0.1.4 release title was corrected to `v0.1.4`. Production firewall limits
cover both backend feedback paths and the PWA proxy. The backend credential
is stored as a Vercel production secret.

## Verification

Run `cargo test --locked`, `cargo check --locked --all-features`, and
`npm test --prefix web`. Native UI checks require a disposable X11/D-Bus session;
never run GUI automation against a user's existing desktop.
Mac and Windows packaging still require their CI runners before publishing.
